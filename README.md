# FuelGuard AI ⛽🤖

FuelGuard AI is an intelligent fuel management and monitoring platform designed to help users track fuel usage, monitor expenses, analyze consumption patterns, and improve efficiency through AI-powered insights.

---

## 🚀 Features

- 📊 Real-time fuel usage tracking
- 🤖 AI-powered analytics and insights
- 📈 Interactive dashboard and reports
- 🔔 Smart alerts and notifications
- 🧾 Expense monitoring
- 🔐 Secure authentication system
- ⚡ Fast and responsive UI
- 🌐 Modern full-stack architecture

---

## 🛠️ Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Prisma ORM

### Database
- SQLite / Prisma Database
